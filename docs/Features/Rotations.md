# Rotations — Formation Sequence Creator

## Purpose

Rotation Studio is a fullscreen coaching workspace for building volleyball **formation sequences**, not a permanent ghost-token path editor.

Coaches select a system, assign real roster players to roles, and save multiple formation states for each rotation. Preview animations show movement between two saved formations.

## Product model

### Rotation Plan

- Plan name
- Organization / team / season
- System type
- Libero usage
- Role assignments from the real roster
- Six rotations, each containing named formations

### Supported systems (v1)

- 4–2
- 5–1
- 5–1 without Libero
- 6–2
- 6–2 without Libero
- Custom

### Formation states per rotation

Recommended defaults:

- Home / Base
- Serve Receive
- Attack after Receive
- Serve / Stack
- Defense / Base
- Attack after Defense
- Defense Left
- Defense Right

Each formation stores:

- Player coordinates (normalized logical court space)
- Ball coordinates
- Active server
- Libero replacement state
- Optional substitutions
- Optional annotations / coach notes

## Court

- Fullscreen studio shell
- Premium 2.5D / perspective appearance via CSS/SVG projection
- Logical coordinates in storage; screen projection is visual only
- Helpers: `logicalToScreen()` and `screenToLogical()`
- Depth-aware token scale and shadows
- Independent draggable ball

## Interaction

- Drag players directly on the court
- Compact radial actions: Mark Server, Libero Replace, Substitute, Reset Position, Player Details
- Formation sequence tabs with previous/next
- Rotate advances R1 → R6
- Play Sequence / Preview Transition animates between saved states

### Transition preview rules

1. Current positions remain briefly visible
2. Starting positions become temporary ghosts
3. Real tokens animate to the destination formation
4. Temporary arrows trace movement and stop before destination tokens
5. Ball animates to its destination
6. Ghosts and paths disappear at completion
7. Replay works every time

Do **not** show permanent ghost tokens during normal editing.

## Substitutions

Some systems suggest substitutions by rotation (for example setter specialist patterns). Suggestions are:

- Generated by the system template
- Editable, optional, accept/dismiss
- Stored on the plan
- Separated from Libero replacements
- Always use real roster players

## Architecture

```
src/features/rotation-studio/
  components/
  templates/
    fourTwo.ts
    fiveOne.ts
    sixTwo.ts
  types.ts
  projection.ts
  persistence.ts
  validation.ts
```

Templates are data, not hardcoded JSX. Defaults are editable coaching starting points, not the only legal tactical shape.

## Persistence

- Versioned plan storage scoped to organization / team / season
- Integrated with the existing local workspace approach
- Safe migration path that discards or ignores unfinished experimental `scoreflow-rotation-studio-v2` ghost-path data without crashing

## Out of scope for the first pivot

- Permanent ghost-token editing as the primary model
- WebGL courts
- Full overlap enforcement as a hard block (warnings can come later)
- Cloud sync / team portal sharing
