## Implementation Notes

Scoring is immutable. A set-winning point stores the completed set and either advances to 0-0 or ends the match. Undo pops the previous snapshot, so it can reverse a set that just completed. `subtract` only lowers the current set score and cannot unwind a finished set.

Vite does not own the repo-root `index.html`. Current app: port 4173. Rebuild: port 5173.
