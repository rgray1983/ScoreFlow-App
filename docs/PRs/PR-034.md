# PR-034 — Account on Home, scorer name, and avatar

## Status

Ready for local testing and review.

## Branch

`cursor/account-home-avatar-feac`

## Purpose

Put Account in the Home chrome next to Settings. Give scorers a dedicated Account screen to sign in, set a display name, and change their photo. Save that profile on live games so a later viewer can show who’s scoring.

## Scope

- Home top-right: account avatar, then Settings
- `/account` screen: large photo, display name, sign-in / sign-out
- Settings opens Account instead of embedding the sign-in form
- Profile saves on this device; signed-in users also sync name/photo to the cloud
- Live games store `scorerName` and `scorerAvatar` (not shown on the viewer yet)

## Implementation Notes

The Account screen follows the common phone-app pattern: identity first (photo + name), then sign-in. Guests can still set a name and photo on this device. Signed-in Google photos seed the avatar only if the scorer has not picked one.
