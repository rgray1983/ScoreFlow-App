## Status

## Purpose

Phase 6 of `docs/SCOREBOARD_REBUILD.md`: fan chat and reactions on the viewer, plus a small scorer pause-chat control. One Fan Zone markup tree reflows for portrait and landscape.

## Scope

- Viewer chat (60 chars) and the gym reaction set: ❤️ 🔥 👏 🎉 🏐 💪
- Name prompt stored per device/session, not as a global default
- Client cooldowns: 1.8s chat, 650ms reactions
- Existing Firestore rules; no Cloud Functions throttle
- Scorer **Chat On / Chat Off** while live
- Portrait: full Fan Zone under the board. Landscape: toasts + reaction strip, Chat opens the composer
- Root `index.html` / `app.js` unchanged

## Implementation Notes

Chat writes match the gym payload: `text`, `name`, `role`, `sessionId`, `uid`, `createdAt`, `createdAtMs`. Scorer pause is `chatPaused` on the game document (owner merge). Viewer input disables when paused; reactions still send.
