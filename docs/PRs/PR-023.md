## Implementation Notes

Chat writes match the current-app payload: `text`, `name`, `role`, `sessionId`, `uid`, `createdAt`, `createdAtMs`. Scorer pause is `chatPaused` on the game document (owner merge). Viewer input disables when paused; reactions still send.

Landscape does **not** open a composer. That Chat toggle was a rebuild invention. The current ScoreFlow viewer hides chat in landscape and shows toasts + the reaction strip.

Floating reactions spawn on `document.body` and drift up with the same 5.2s motion as the current app. The chat-name prompt is a native modal `dialog` on the top layer so the name field and Start Chatting stay tappable.
