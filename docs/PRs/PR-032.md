# PR-032 — Setup fields, select-to-replace, and color bars

## Status

Ready for local testing and review.

## Branch

`cursor/setup-fields-color-bar-feac`

## Purpose

Stop iPhone zoom when tapping text fields. Tap a field to highlight the value so typing replaces it. Generalize Home Team placeholders. Color pickers stay a color bar until you open them, so scrolling Match Setup does not change a color by accident.

## Scope

- Text inputs use 16px so iOS does not zoom on focus
- Tap a text field selects the current value
- Home Team placeholders: `Team Name` and `City, State`
- Color picker collapsed to a color bar; tap to edit, Save Color to close
