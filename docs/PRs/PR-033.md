# PR-033 — Center Match Result and honor the Settings graphic

## Status

Ready for local testing and review.

## Branch

`cursor/match-results-center-graphic-feac`

## Purpose

Center the Match Result recap on the screen. Save the Background Graphics pick in Settings and use that graphic on Match Result and Share/Download.

## Scope

- Match Result dialog is a full-viewport overlay and centers the recap card plus Share/Download button
- Settings → Background Graphics writes `scoreflowPremiumV1` and the recap reads that value, not the graphic stamped when the match ended
- Live match recap also passes the current Settings graphic
- Free Default Blue still persists without Pro; Pro graphics stay locked until Try Pro

## Implementation Notes

The winner overlay used to build the recap without `resultBackground`, so Match Result always showed Default even after a free graphic was saved. Recaps now overlay the current Settings pick so changing graphics updates Match Result immediately.

## Testing Checklist

- [ ] Run in VS Code (commands below)
- [ ] Open Match Result — recap and Share/Download sit in the middle of the screen
- [ ] Settings → Background Graphics → Default Blue (or another free graphic) — reopen Match Result and the new graphic is on the recap
- [ ] Share/Download uses the same graphic
- [ ] Pro graphics still toast and stay locked unless Try Pro is on

## Known Limitations

Pro backgrounds still require Try Pro / Pro. Changing the graphic does not rewrite older history records; the recap overlay uses the current Settings pick either way.
