# PR-026 — Phase 10 Style and Polish

## Status

Ready for local testing and review.

## Branch

`cursor/phase-10-style-polish-feac`

## Purpose

Phase 10 of `docs/SCOREBOARD_REBUILD.md`: make the Vite rebuild look and feel like the current ScoreFlow scoreboard. Cutover (Phase 9) waits until this is signed off. Production stays on root `index.html` / `app.js`.

## Scope

- Match and viewer copy the current glass broadcast board: huge Anton scores, team-color +1, quiet −1, dotted colon, Set box
- Live pill: Online / Offline / Connecting / Sync Error
- Button hierarchy: red Start / +1, gold Share Live, quiet New Match / Undo / Back
- Shared pills are 40px tall, single-line. Match Won uses End Match instead of Share Live. Share Results tries to lock portrait and asks you to rotate in landscape.
- Viewer: Prematch overlay on load, then the Fan Zone chat-name prompt after **Watch Live Score**, then the live board
- Scorer portrait matches the current board: current top bar with rounded corners, teams/logos on the glass card, +1/−1 under the scores, Fan Zone in the bottom third
- Viewer header logo is centered even when Viewers / Online sit on the right
- Reloading the scorer reconnects the same live match ID so the open viewer keeps updating
- Long team names stack on two lines instead of shrinking to a tiny one-line size. Landscape logos stay the same size on both sides; extra name height comes from the spacer above the buttons.
- Viewer logos go out on the live game document as soon as Share Live starts, then Storage URLs replace them when upload succeeds.
- Setup: Start Scoreboard and Start Live Scoreboard, same as the current app
- Home primary: Start A Match. Resume Match only appears when a live session, recovery, or in-progress match can be returned to — not after End Match
- Match Setup text fields keep spaces while typing; names trim when the match starts
- Winning a match plays trophy + confetti first, then Match Won. Viewer trophy popup is compact so the board stays visible behind the confetti.
- Match Setup uses the Home Team color picker for both teams. Scorer can tap a board logo to upload the visitor (or home) mark. Dropdowns use a dark menu so options stay readable.
- Match and viewer use the current volleyball court photo behind the glass board, top bar, and Fan Zone. Home and Setup stay the dark arena cards.
- Viewer Live Match welcome and Ended both use logos and stacked names. Ended also marks the winner and shows set wins under VS.
- Landscape viewer board has a quiet “Rotate for chat” hint in the bottom-right corner.
- Keep `app.js` — still the live product and the look reference
- Root `index.html` / `app.js` unchanged
