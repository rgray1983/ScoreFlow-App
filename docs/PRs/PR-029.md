# PR-029 — iPhone home-screen app fills the screen

## Status

Ready for local testing and review.

## Branch

`cursor/ios-pwa-fullscreen-feac`

## Purpose

When ScoreFlow is saved to an iPhone home screen, a black band sat under Match Setup and the rest of the app. The arena should paint to the physical bottom of the screen. Buttons still clear the home indicator via existing safe-area padding.

## Scope

- Keep `100dvh` in a Safari tab so the URL bar does not create a gap
- Home-screen / standalone mode uses `100vh`, which includes the band WebKit omits from `100dvh`
- Pin `#root` to the screen edges in standalone mode
- Mark `html.scoreflow-standalone` from `navigator.standalone` so iOS gets the same layout even before `display-mode` matches
- Do not change scoring, live share, or Firestore

## Files Changed

- `docs/PRs/PR-029.md`

## Implementation Notes

This is a WebKit installed-PWA quirk: with `viewport-fit=cover` and a translucent status bar, `100dvh` is the screen minus the bottom (and sometimes top) inset. The leftover is the OS webview’s black background.

After this ships, delete the old home-screen icon and add ScoreFlow to the Home Screen again so iOS picks up the updated shell. Then open the icon (not Safari).
