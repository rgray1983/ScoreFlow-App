# PR-037 — Timeout lights

## Status

Ready for local testing and review.

## Branch

`cursor/timeout-lights-feac`

## Purpose

Phase 1 add-on #3: two timeout lights per team per set. Scorer taps a light to call it. Viewer gets a 45 second popup. Undo restores a mis-tap. Scoring stays live.

## Scope

- `homeTimeouts` / `awayTimeouts` (0–2), `activeTimeout`, and `timeoutEndsAtMs` on the match
- Tap a remaining light on the scorer to call that team’s timeout
- Viewer shows the same lights, not tappable
- 45s clock: compact timer + **End timeout** on the scorer; larger team-colored popup on the viewer
- Clock clears at 0 so the scorer is not stuck; ending early is undoable
- Undo of a timeout call restores the light
- New set restores two lights each and clears any running clock
- +1 and Undo still work during a timeout
- Live games write timeout remaining + the clock end time so the viewer matches
- Old live docs without timeout fields default to two lights, no clock

## Implementation Notes

The end timestamp lives on match state so undo can restore the clock without ticking the reducer. An expired timeout clears in place (no extra undo frame) so the next Undo still targets the timeout call. Early **End timeout** does snapshot, so Undo brings the timer back.
