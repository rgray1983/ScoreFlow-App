# PR-028 — Swipe to delete match history

## Status

Ready for local testing and review.

## Branch

`cursor/history-swipe-delete-feac`

## Purpose

Let a scorer swipe a saved match left on Home or Match History and tap Delete. That clears leftover test matches from **this device** without sharing anyone else’s history.

## Scope

- Swipe a history row left to reveal a red Delete button, same pattern as Mail and similar apps
- Delete removes the match from local history on this phone/computer
- If the scorer is signed in, also delete that match from their cloud backup so it does not come back
- History page copy mentions the swipe

## Implementation Notes

Home Team, settings, and match history stay on that device. Sending the ScoreFlow app link does not send saved teams or history. A live viewer link still only shows that one match.

## Testing Checklist

- [ ] Run in VS Code (commands below)
- [ ] Home or Match History: swipe a saved match left, tap Delete
- [ ] Reload the page — that match is gone
- [ ] Tap a match (no swipe) still opens the recap

## Known Limitations

Delete does not remove a live game that families are still watching. It only removes the saved recap on this device (and that account’s backup).
