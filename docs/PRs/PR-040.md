# PR-040 — Pro saved teams, player highlights and continuing chat

## Status and branch

One review PR on `agent/pr-040-teams-play-by-play`, based on current main `88ae9e1205303d66fae555d0763b7342a59331b5`. Requested by Richie after the approval/merge of PR-039. Leave unmerged and undeployed until he tests and approves.

## Result

A Pro parent scorer can save separate teams and simple rosters, choose a team before the match, then open a small Roster tab, select a player and choose Ace, Kill or Block. The action adds exactly one home point and creates a viewer announcement. +1 stays primary, and the existing team-level Call controls stay available. Only the scorer's team has player actions. This does not introduce Coach, billing, statistics, opponent lineups or non-scoring actions.

Portrait viewers switch between Chat and Play by Play. Landscape highlights pop up and fade out like chat. Undo removes the scored action and its announcement. Chat and reactions now follow the latest window rather than freezing after the first 40/60 events, and older chat messages can be paginated.

## Review fix — general team calls

Richie reported that team-level calls appeared locally but not in the viewer. The initial feed filtered out calls without a player, leaving general calls dependent on the transient `lastHighlight` and its short-lived visual effect. A quick follow-up point or slow/coalesced publication could lose the announcement.

All surviving team-level calls now enter the same durable feed as player calls, with their team name and set/score captured at the scoring action. Both sides' general Call controls work without Pro/rosters; named player calls remain limited to the scorer's Pro roster. New viewers use the compact feed popup once per call, with the original burst retained as a legacy-game fallback. Undo, set transitions, reload and ordinary follow-up points retain the correct feed. A separate-context browser regression checks all three actions, both sides, offline coalescing, landscape popups, portrait history, Undo and no replay on reload.

The same review fix enables landscape chat popups on the scorer in the viewer's existing popup position. The scorer still hides the landscape reaction controls, and popups remain non-interactive so scoring buttons work through them. Browser coverage sends chat from an independent viewer, verifies it appears at the same coordinates on both screens and scores while the popup is visible.

## Implementation

- `storage/teams.ts`: versioned local team book, stable team/player IDs, preserved legacy Home Team branding, independent roster parsing, selected team persistence. Pro checks at UI and workspace boundaries; Free edits do not erase saved Pro rosters.
- `storage/matchContext.ts`, workspace and setup: match-specific branding/roster snapshot independent of future team edits or selections. Existing on-device engine/Undo history remains the scoring source of truth.
- `ui/RosterDrawer.*`: responsive side drawer, player/action sliding panels, native modal focus containment, Escape/close controls and duplicate-tap guard. Approximately one-third width in landscape, wider as needed on narrow phones for readable names and 44px+ actions.
- Scoring highlights carry a team name and set/score snapshot, plus an optional player. `scoring/plays.ts` derives surviving unique announcements from Undo history, avoiding copying a growing feed into every history state. Set-winning calls persist through the next-set gate. Feed resets with new/replacement matches.
- Live outbox stores the complete surviving play feed with the latest score. Both are written in one owner/revision-checked transaction, retaining offline plays even when intermediate score snapshots are coalesced. Terminal end, reconnect, account fences and viewer IDs retain PR-039's behavior.
- Public game snapshots contain announced players only; full private roster/profile data stays on-device. No separate chat writes or production rules changes are needed for player events.
- `ui/FanZone.*`: separate tabs, unread play dot, landscape toasts, Undo removes an active popup, listener/timer cleanup and pagination request guards. New chat does not jump the scroll while someone reads earlier messages. After a disconnect longer than the latest window, pagination restarts from a contiguous newest page so missing messages can still be loaded.
- `live/fanZone.ts`: ascending `limitToLast` latest-window subscriptions, stable timestamp/document-ID chat pagination, deduplication and initial-server-snapshot guards against replaying old chat/reactions.

## Deliberate limits

Pro is still the existing local **preview**, not a paid entitlement. Team profiles and rosters are saved on this device/browser; cross-device roster backup is not included. Existing cloud account/match backup is unchanged. Keep local browser storage intact. Live offline recovery requires a previously authenticated identity and the same owning UID. Physical devices and actual gym Wi-Fi still need Richie's validation. Play by Play is the optional selected highlights, not an official rally log or statistics feature. Chat history is retained remotely; no automatic deletion/retention service is added.
