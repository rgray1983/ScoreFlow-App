# PR-020 — Phase 4 Match Scoring

## Status

Ready for local testing and review.

## Branch

`cursor/phase-4-match-scoring-feac`

## Purpose

Phase 4 of `docs/SCOREBOARD_REBUILD.md`: wire the Match screen through `src/scoring` so a scorer can run a full club or high-school match offline, including Undo through a completed set.

## Scope

- `+1`, `−1`, Undo, New Match, and Home on one reflowing board
- Set point / match point banners from scoring queries
- Winner overlay after match point, with Undo and New Match
- New Match uses an in-app dialog (no native `confirm()`)
- Persist the live engine locally so a refresh keeps the score
- Share Live stays disabled (Phase 5)

## Files Changed

- `src/scoring/queries.ts` — `matchBanner()`
- `src/state/workspace.ts` — engine + `dispatch(command)`
- `src/storage/matchEngine.ts`
- `src/screens/MatchPage.tsx`, `SetupPage.tsx`
- `src/ui/Dialog.tsx`
- `docs/SCOREBOARD_REBUILD.md`, `docs/PRs/PR-020.md`

## Implementation Notes

Screens never mutate scores by hand. Every tap is a `Command` through `reduce()`. Logos stay on the match draft; names, colors, and scores live on the engine. Going Home does not end the match.
