# PR-018 — Phase 2 App Shell

## Status

Ready for local testing and review.

## Branch

`cursor/phase-2-app-shell-feac`

## Purpose

Phase 2 of `docs/SCOREBOARD_REBUILD.md`: a navigable ScoreFlow shell with routes, design tokens, self-hosted fonts, compressed PWA icons, and a service worker for the Vite app only. Scoring is not wired.

## Scope

- React Router screens: `/`, `/setup`, `/match`, `/g/:gameId`, `/history`, `/settings`, `/settings/themes`, `/settings/graphics`
- Keep the current ScoreFlow look: dark arena, red primary, gold share, quiet secondary, SVG icons
- Self-host Inter and Anton
- Compress PWA icons into `src/public` (512px ~265KB vs the old ~2.1MB file)
- `vite-plugin-pwa` writes `dist/sw.js` for the new shell only. Root `service-worker.js` is unchanged.

## Files Changed

- `src/App.tsx`, `src/main.tsx`, `src/index.html`
- `src/ui/**`, `src/screens/**`, `src/pwa/register.ts`
- `src/public/icon-180.png`, `icon-192.png`, `icon-512.png`, `scoreflow-logo.png`
- `vite.config.ts`, `package.json`, `package-lock.json`
- `docs/SCOREBOARD_REBUILD.md`, `docs/PRs/PR-018.md`
