# PR-030 — Hide scrollbars app-wide

## Status

Ready for local testing and review.

## Branch

`cursor/hide-scrollbars-feac`

## Purpose

Remove visible scrollbars everywhere so ScoreFlow feels like a home-screen app, not a web page. Pages still scroll.

## Scope

- Hide scrollbars on every overflow area (Home, Match Setup, History, Fan Zone, dialogs)
- Keep touch / trackpad / mouse-wheel scrolling
- No scoring, live, or hosting changes

## Files Changed

- `docs/PRs/PR-030.md`
- `src/ui/base.css`

## Implementation Notes

Firefox uses `scrollbar-width: none`. Safari and Chrome use `::-webkit-scrollbar { display: none }`. Content that already uses `overflow: auto` still moves.

## Testing Checklist

- [ ] Run in VS Code (commands below)
- [ ] Home, Match Setup, Settings, History: scroll without seeing a scrollbar
- [ ] Viewer Fan Zone still scrolls
- [ ] You can still reach Start Scoreboard at the bottom of Match Setup

## Known Limitations

A brief overlay indicator can still flash on some iPhones while you drag. That is the system scroll hint, not a gutter scrollbar.
