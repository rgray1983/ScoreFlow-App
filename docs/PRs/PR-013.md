# PR-013 — New Firebase Browser API Key

## Status

Ready for local testing and review.

## Purpose

PR-013 follows the already-merged live-auth fix. Anonymous live sessions still failed because the old browser API key was accepted for Firestore and rejected for Identity Toolkit. This updates `firebase-config.js` to a new Browser key and keeps live writes from using leftover game IDs.

## Scope

- Replace the Firebase web `apiKey` with a key that Identity Toolkit accepts.
- Stamp live game `ownerId` from `auth.currentUser.uid` after Auth is ready.
- Start a fresh live game from Match Setup instead of writing into an old game.
