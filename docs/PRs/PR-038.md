## Scope

- Persistent set-point / match-point atmosphere, with team color and a gold rim.
- Classic, Old School, and Flip Clock board looks. The picker is the small board icon beside Match Setup. It changes only the scoreboard and its viewer, persists on this device, and stays selected for a new match.
- Quiet Account display-name credit. Nothing is shown when no name is set.
- Momentum warms at 3 consecutive points, shows a run badge at 5, and intensifies at 7. Side-out and Undo restore the appropriate state. A score subtraction clears uncertain momentum.
- Next-set and deciding-set cards. Scorer must tap **Start Set N**; viewers hold the same card, including after reload. Undo reverses the set-winning rally even after continuing.
- **Call → Ace / Kill / Block**, each adding one point and playing a distinct nonblocking hit. Regular +1 stays primary. Undo removes the point and hit together. No player statistics.
- Optional short haptic feedback on supported scorer devices.
- Portrait/landscape layouts, including 320×568 and dark-skin contrast.
- Isolated live branding writes, stale-upload guards, and preservation of points entered during initial live creation. Score updates cannot reopen an ended game.
- Auth/Firestore/Storage emulator mode for browser testing, a demo project and production-request guard, CI build checking, and a separate E2E dev-server port.
- Root README, current-status checklist, and setup assessment.

## Implementation notes

### Changes requested during Richie's review

- Timeouts now start at **1:00** on scorer and viewer. Timeout lights, early End timeout, and Undo keep their existing behavior.
- Match Results set scores have a subtle centered white glow, preserving team colors in both the on-screen recap and shared/downloaded PNG. The glow is scoped to scores.

New live/state fields are `boardTheme`, `runSide`, `runLength`, `pendingSet`, and `lastHighlight`. Legacy saved matches and live documents default safely. They do not infer a run from an old score.

The reducer records a completed set and prepares the next set at 0–0, then sets `pendingSet`. Both UIs cover the board with the prior set's score card until the scorer clears the gate. Continue adds no undo frame; Undo still reverses the winning rally. There is no set card after a match-winning point.

Highlights use unique IDs and a short validity window. An already observed hit does not replay on Undo; saved hits do not replay on a scorer reload. A nonmodal top-layer burst can sit over a set card without blocking its controls. Reduced-motion preferences disable the new animations.

Board appearance is deliberately independent of the existing Pro color themes. This does not introduce a paywall or change billing.

Firebase emulator wiring is development-only. Automated tests use `demo-scoreflow`, block production Firebase endpoints, start their own server on 5174, and stop their emulators afterward. Normal `npm run dev` still uses the existing backend.
