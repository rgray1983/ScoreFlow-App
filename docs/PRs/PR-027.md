# PR-027 — Phase 9 Cutover

## Status

Ready for local testing and review.

## Branch

`cursor/phase-9-cutover-feac`

## Purpose

Phase 9 of `docs/SCOREBOARD_REBUILD.md`: make the Vite app the live ScoreFlow product. GitHub Pages serves the production build. The old root `index.html` / `app.js` / `style.css` entry is removed.

## Scope

- Production hosting: GitHub Actions builds Vite with `VITE_BASE=/ScoreFlow-App/` and deploys `dist/` to GitHub Pages
- SPA fallback: copy `index.html` to `404.html` so `/g/:gameId` works on Pages
- Old `?game=` / `mode=view` links redirect to `/g/:gameId`; `mode=scorer` goes to `/match`
- Delete unused current-app files: root `index.html`, `app.js`, `style.css`, `manifest.json`, `service-worker.js`, `firebase-config.js`, splash/icons
- Unregister the old `service-worker.js` so installed PWAs pick up the Vite app
- Playwright: a scorer point appears on the live viewer
- Firestore rules unchanged
