# PR-036 — Serving mark

## Status

Ready for local testing and review.

## Branch

`cursor/serving-mark-feac`

## Purpose

Phase 1 add-on #2: show which team has the serve. Scorer taps it to start a set. Points then keep or flip serve. Undo restores it. Viewer is read-only.

## Scope

- `servingSide` on the match (`""` | `"home"` | `"away"`)
- Tap the mark under a logo to set first serve (or to correct it)
- A point keeps serve for that team and side-outs to the other team
- New set clears serve so they tap again
- Live games write `servingSide` so the viewer matches
- Viewer shows the pulsing volleyball + Serving pill, no tap
- Portrait scorer and viewer put team names / set wins above the logo (same as landscape)
- Viewer portrait parks the ScoreFlow logo on the left of the top bar, sized to the bar

## Implementation Notes

Minus-one does not guess the previous serve. Undo does. The serving mark sits under the logo, not on it, so tapping a logo still uploads art.
