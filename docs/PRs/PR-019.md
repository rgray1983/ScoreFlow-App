# PR-019 — Phase 3 Home Team + Match Setup

## Status

Ready for local testing and review.

## Branch

`cursor/phase-3-home-team-setup-feac`

## Purpose

Phase 3 of `docs/SCOREBOARD_REBUILD.md`: save a home team on this device, set up a match (title, format, names, colors), and open `/match` with that branding. Scoring stays disabled until Phase 4.

## Scope

- `/team` home-team screen: name, city/state, logo upload, HSV color picker
- Persist home team in `localStorage` under the existing `scoreflowHomeTeamV2` key
- Resize logos on upload (max 256px, WebP then PNG data URL)
- `/setup` match form: title, club vs high school, home/visitor names and color swatches
- Persist an in-progress match draft locally (`scoreflowMatchDraftV1`)
- Fill home name/color/logo from the saved home team unless the scorer already typed a custom home name
- `/match` shows the chosen names, colors, logos, title, and format. +1 / Undo / Share stay disabled

## Implementation Notes

Zustand is the thin UI store locked in the rebuild map. Scoring still does not run on Match. Logo bytes stay on-device as resized data URLs; Firebase Storage is Phase 5.

If a gym already saved a home team in the current app, this rebuild reads the same `scoreflowHomeTeamV2` key.
