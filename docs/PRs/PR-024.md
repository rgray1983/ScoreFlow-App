# PR-024 — Phase 7 History + Results Graphic

## Status

Ready for local testing and review.

## Branch

`cursor/phase-7-history-results-feac`

## Purpose

Phase 7 of `docs/SCOREBOARD_REBUILD.md`: save completed matches locally, show them on Home and `/history`, and share/download the results PNG from the winner overlay. The current `index.html` / `app.js` / `style.css` app is the source of truth.

## Scope

- Persist completed matches in `scoreflowMatchHistoryV2` (same key as the current app)
- Free-plan cap of 3 matches
- Home shows the latest 3; `/history` lists saved matches
- Tap a history card to open the recap
- After match point, **Share Results** (or closing the winner overlay) opens the recap
- **Share/Download Results** builds the 1080×1920 PNG and uses native share, or downloads
- Team names are React text, not `innerHTML`
- Root `index.html` / `app.js` unchanged
