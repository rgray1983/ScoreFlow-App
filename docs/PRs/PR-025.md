## Implementation Notes

The current Settings HTML does not include email/Google/Apple fields, but `app.js` already has that account flow and backup requires a real account. Settings now has an Account card that uses the same email, Google, and Apple behavior. Apple may show “needs to be enabled” until the domain is ready. Pro is a clearly labeled preview, not billing.

Cloud writes stay under `users/{uid}` for premium settings, match history, and the saved home team. Anonymous live Auth is a different UID and does not write backup docs.
