# PR-021 — Phase 5 Live Share + Viewer

## Status

Ready for local testing and review.

## Branch

`cursor/phase-5-live-share-feac`

## Purpose

Phase 5 of `docs/SCOREBOARD_REBUILD.md`: anonymous Auth, an unguessable live game ID, scorer stays on `/match`, families watch `/g/:gameId`, on-device QR, presence/viewer count, and a recovery prompt if a live game is still open.

## Scope

- `src/live` adapters for Auth, Firestore, Storage, presence, recovery
- Share Live creates a 128-bit hex game ID (not `game-${Date.now()}`)
- Logos upload to Storage; the game doc stores URLs only
- Point taps send the small score payload
- Viewer route is read-only and pinch-zoomable
- Home asks Resume vs End if a live match was left running
- Chat / reactions stay Phase 6

## Implementation Notes

The scorer URL stays `/match`. The viewer link is `/g/{gameId}` on this Vite app (port 5173). Root `index.html` / `app.js` still use the old `?game=` links until Cutover.

`localhost` must stay in Firebase Auth authorized domains for local live tests.
