# PR-031 — Disable pinch-zoom

## Status

Ready for local testing and review.

## Branch

`cursor/disable-pinch-zoom-feac`

## Purpose

Pinch-zoom was on for the whole app, including the scorer. That fights gym scoring. Lock the scale so ScoreFlow stays 1:1.

## Scope

- Viewport: `maximum-scale=1, user-scalable=no`
- `touch-action: manipulation` on the app shell (no pinch or double-tap zoom)
- Viewer no longer opts into `pinch-zoom`
- Block iOS `gesturestart` / two-finger `touchmove`
- Update the rebuild UI rule

## Files Changed

- `docs/PRs/PR-031.md`, `docs/SCOREBOARD_REBUILD.md`
- `src/index.html`, `src/main.tsx`, `src/ui/base.css`
- `src/pwa/zoom.ts`, `src/pwa/zoom.test.ts`

## Implementation Notes

Safari tabs sometimes ignore `user-scalable=no`. The gesture lock is what stops pinch on iPhone. One-finger scrolling still works.

## Testing Checklist

- [ ] Run in VS Code (commands below)
- [ ] On a phone: pinch on Home, Match Setup, the scoreboard, and the viewer — the UI must not scale
- [ ] Scroll Match Setup and History with one finger
- [ ] +1 still registers a single tap

## Known Limitations

iOS Settings → Accessibility → Zoom is a system feature and cannot be blocked by a web app.
