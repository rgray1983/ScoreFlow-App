# Scoreboard add-on ideas

Captured 25 Aug 2026 from the live ScoreFlow app (not the old rebuild roadmap). These stay a **scoreboard**: points, sets, live viewer, energy. Not Coach, roster, rotations, or player stats.

Source of truth for what we build next is Richie’s picks in `PHASE_1_ADDONS.md`. This file keeps the full list so later versions can pull from it.

Gym / TV / walk-up QR ideas are **later versions**, not Phase 1.

## Phase 1 (chosen)

### 2. Serving-team mark

A serving cue on the team that has the ball. Prefer a **“Serving” pill under the logo** and/or a **small pulsing volleyball** on that side. First serve of a set is a tap. After that, side-out can follow the points.

### 3. Timeout lights + 45s viewer popup

Scorer taps a timeout for a team. Timeout lights on that side go down. Viewer (and the live board) get a **45 second timer popup** with the team who called it.

### 4. Match-point atmosphere

When the next point can end the set or the match, the whole board shifts: darker, scoring team’s color, digits breathe, gold rim. Snaps back after the point.

### 7. Themed scoreboards

Board skins, not just retinting ScoreFlow red. Ideas: current glass court, **Old School LED**, **alarm-clock flip digits**, and more later. Home / Settings can stay as they are.

### 9. Scorer name on the live board

Account already has a display name (and photo). Put the name somewhere quiet on scorer + viewer so the match feels hosted.

### 10. Run weather

Consecutive points heat up that side of the board — videogame energy, not a stats sheet. A quiet “6–0 RUN” that never hides the score.

### 11. Next-set / deciding-set cards

When a set ends, a full card: “SET 2” or “DECIDING SET”. **Scorer taps to continue.** Viewer holds the card until that tap. Match-won stays the existing trophy / recap, not a second card.

### 13. Highlight calls (Ace / Kill / …) with big animations

Scorer has a control for highlight actions (**Ace!**, **Kill!**, later Block, etc.). Each one scores the point and plays a unique animation (screen breaking apart, “KILL!” zooming at your face). Same FX on the viewer. Regular **+1** stays for normal points.

## Later versions (gym and more)

### 1. Gym screen

A second live URL that is only the board: huge digits, no chat, for an iPad in the window, a TV, or HDMI. Not the phone viewer stretched sideways.

### 5. Live Story card

Mid-match 9:16 score graphic for group chats and Instagram, not only the final poster.

### 6. Tonight’s-team takeover

The whole app (Home, board, viewer, cards) paints itself in the home team’s color for that match.

### 8. Viewer-only arena sound

Scorer stays quiet. Viewers can opt into ticks, a whistle on set point, crowd swell on match point.

### 12. Walk-up QR on the scorer

A small live QR that stays on screen all match so parents can scan without opening Share Live.

### 14. Fan reactions that hit the board

Fan Zone fire/emoji waves actually light the scoring team’s digits for a second.

### 15. Pocket pings for set / match point

Web push (later lock-screen Live Activity) when it actually matters. Not a chat firehose.
